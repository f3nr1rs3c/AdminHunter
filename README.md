# AdminHunter - Web Admin Panel Discovery Tool

🛡️ **Admin Hunter**, bir web sitesinde bulunan **gizli veya yaygın admin panel dizinlerini** hızlı şekilde keşfetmek için geliştirilmiş bir **Python tabanlı güvenlik aracıdır.**

Pentest ve bug bounty süreçlerinde **yetkili testler sırasında** admin panel keşfi için kullanılabilir.

---

# 🚀 Özellikler

- 🔍 **100+ admin panel path taraması**
- ⚡ Hızlı HTTP istekleri
- 🎨 Renkli terminal çıktısı
- 🧠 Basit ve anlaşılır kod yapısı
- 🐍 Python tabanlı
- 💻 Windows & Linux uyumlu

---

# 🛠️ Kullanılan Teknolojiler

Tool aşağıdaki Python kütüphanelerini kullanır:

- **requests** → HTTP istekleri
- **pyfiglet** → Terminal banner
- **colorama** → Renkli terminal çıktısı

---
